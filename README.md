## 本次更新

- 新首页采用天空、大海与动态地球轨道的三层视觉结构，适配桌面、平板和手机。
- 两大研究方向采用图片卡片，分别跳转到 `research.html#atmosphere` 和 `research.html#deepsea`。
- 首页中下方顺序是 **课题组负责人（左）→ 最新动态（中）→ 快速入口（右）**。小屏幕会自动纵向排列。

- “最新动态”只从已有代表性论文数据中生成近期论文记录，展示的是**发表年份而不是虚构新闻发布日期**。点击可进入相应论文的搜索结果。

## GitHub Pages 部署

解压后将本文件夹中的 `index.html`、其余页面和 `assets/` 文件夹一同上传到 GitHub 仓库根目录。GitHub 仓库 **Settings → Pages → Deploy from a branch → main / (root)**。

无须后端、构建工具或外部动画库。Chrome、Safari、Edge 等现代浏览器直接访问 `index.html` 即可。

**正式发布前请核实**：网站名称 `XXX课题组`、所属单位，负责人简介中的“XX校长”，以及仍待确认的主要科研项目演示条目。项目尚无正式资料，不应将演示项目描述为课题组真实完成的项目。

## V40 项目列表维护

主要科研项目现采用与参考文献类似的简洁编号格式，按“大气与空间环境预测”“海洋信息感知与处理”两个方向分组。当前尚未收到正式项目名单，因此旧版六条示例项目已移出公开数据。

后续在 `assets/data.js` 的 `projects: []` 中添加，如：

```javascript
{ category: '大气与空间环境预测', title: '项目正式名称', source: '国家重点研发计划', period: '2023—2027' }
```

`source`、`period` 非必填；页面不会强制展示研究目标、经费、负责人、项目编号等信息。

**关于 B/D 海天摄影图：** 浏览器联网时优先访问 PHOTO_CREDIT.md 中相应 Unsplash 照片。当前执行环境无法下载两张照片到本地，因此随包的 `hero-offline-b.webp` / `hero-offline-d.webp` 是两个外观不同的临时离线背景，**不是对应 Unsplash 实景原图**。若要求完全离线展示正确的 B/D 照片，需要从原始链接下载图片并改用本地路径。
